# Änderungsprotokoll

## 0.1.0 – 20.11.2026 – Steuerungs-Labor (Phase 1, erster Stand)

- Godot-Projekt mit Querformat, Compatibility-Renderer und Anpassung an alle Displaygrößen.
- Steuerungs-Labor: Schlachtfeld mit je drei Truppen pro Seite (Platzhaltergrafik) und einfacher Gegner-KI.
- Drei Gefechtssteuerungen: A (Knöpfe + Wischen), B (Antippen + Ziel), C (Joystick + Feuer, Mehrfingerbedienung).
- Zwei Kanonen-Varianten: Schleuder (mit Flugbahn-Vorschau) und Timing (pulsierender Zielkreis).
- Zeitlupe beim Truppenwechsel, Pause, Neustart.
- Schulnoten nach jeder Runde, Übersicht der Durchschnittsnoten je Kombination.
- Speichersystem mit Versionsnummer, sicherem Überschreiben und Autosave beim Verlassen der App.
- Spielzustand der Kampagne als Grundgerüst für Phase 2.
- Automatische Tests (eigener Test-Runner) und automatischer Build für Browser und Android über GitHub Actions.

- Vision und Grundprinzipien in docs/VISION.md.

Noch nicht in diesem Stand: Platzhalter-Karte mit Zoom (folgt nach der Steuerungsentscheidung).
