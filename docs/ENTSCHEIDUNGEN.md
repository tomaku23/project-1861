# Entscheidungen

Stand: 20.11.2026. Das vollständige Planungsdokument liegt als Claude-Doc „North & South Mobile – Machbarkeit, Architektur & Entwicklungsplan“.

## Entschieden

| Datum | Entscheidung | Warum |
| --- | --- | --- |
| 20.11.2026 | Spaßprojekt, vorerst nicht kommerziell | Aufwand zählt nicht, Spielspaß schon |
| 20.11.2026 | Die Steuerung ist die Kernaufgabe; Phase 1 beginnt mit dem Steuerungs-Labor | Wenn das Gefecht auf dem Handy keinen Spaß macht, ändert das den ganzen Plan |
| 20.11.2026 | Godot 4.7, GDScript, reines 2D, Compatibility-Renderer | kostenlos, offline, läuft auch im Browser, Claude kann die Dateien direkt schreiben |
| 20.11.2026 | Story-Modus vom Soldaten zum General; Soldaten-Szenen als 2D-Action, kein 3D-Shooter | verbindet die drei Spielebenen und erklärt das Spiel nebenbei |
| 20.11.2026 | Arbeitsrechner Windows-Laptop, Android-Tests auf OnePlus, iPhone-App erst mit Mac | iOS-Apps lassen sich nur auf macOS bauen |
| 20.11.2026 | Interner Codename „Projekt 1861“, kein „North & South“ | der Name ist eine aktiv lizenzierte Marke |
| 20.11.2026 | Fraktionen über Farben (Blau/Grau), keine Konföderierten-Flagge | Store-Risiko, eigene Bildsprache |
| 20.11.2026 | Vision in docs/VISION.md ist die Leitlinie: eigenes Spiel statt Remake | Inspiration für ein Spielgefühl, keine Kopie |
| 20.11.2026 | Zwei Modi: leichter Einstiegsmodus und Kampagne mit Story vom Soldaten zum General | Zugänglichkeit und Tiefe getrennt anbieten |
| 20.11.2026 | Schlachten sind dynamisch und lassen Zeit, auf Wetter, Sicht und gegnerische Taktik zu reagieren | Information ist kein Siegversprechen (Prinzip 3) |
| 20.11.2026 | KI heißt klassische Spiel-KI, die offline läuft – keine Sprach-KI im Spiel | offline, ohne Server und Kosten |

## Offen (bis Phase 2)
